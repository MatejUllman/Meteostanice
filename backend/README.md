# Mstanice API

Návod na spuštění programu:

- Vytvořte mysql databázi s názvem a importujte do ní soubor init.sql
- Přejmenujte soubor .env.example na .env a nastavte v něm proměnné pro připojení k databázi.
- pip install virtualenv
- virtualenv venv
- venv\Scripts\activate
- pip install -r requirements.txt
- fastapi dev
